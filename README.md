# Analytical Replication and Theoretical Verification of Cosmological Parameters (H0 & q0)

## 🎯 Overview
This repository contains a rigorous analytical review and mathematical replication of the theoretical framework used to estimate the Hubble constant ($H_0$) and the deceleration parameter ($q_0$) from Type Ia Supernovae observations.

## 📊 Methodology & Analytical Scope
- **Metric Framework:** Verification of the Friedmann-Lemaître-Robertson-Walker (FLRW) metric properties for a flat universe ($k=0$).
- **Algebraic Derivations:** Step-by-step validation of the 3rd-order Taylor series expansions for the cosmic scale factor $a(t)$ and its transition to redshift ($z$) space.
- **Model Auditing:** Critical analysis of the MLCS2k2 light-curve fitter constraints on dark energy parameters against the standard $\Lambda$CDM model.

## 🛠️ Tools Used
- LaTeX for scientific typesetting and equation layout.
- Analytical derivation and mathematical auditing.
